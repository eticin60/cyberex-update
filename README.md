### Installation Instructions

1. **Enable Unknown Sources**
   - Go to `Settings` → `Security` → Enable `Install from Unknown Sources`
   - Or allow installation when prompted

2. **Download APK**
   - Click the download link above
   - Or visit our [website](https://cyberex.com.tr/download.html)

3. **Install**
   - Open the downloaded `.apk` file
   - Follow the installation prompts
   - Launch CyberEx!

> [!WARNING]
> Do not download APK files from untrusted sources. Only use official links from `cyberex.com.tr` or this GitHub repository.
