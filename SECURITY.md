## Reporting a Vulnerability

We take security seriously at CyberEx. If you discover a security vulnerability, please report it responsibly.

### How to Report

**DO NOT** create a public GitHub issue for security vulnerabilities.

Instead, please report to:

- 📧 **Email**: security@cyberex.com.tr
- 🐛 **Bug Bounty Program**: [cyberex.com.tr/bug_bounty](https://cyberex.com.tr/bug_bounty.html)

### What to Include

Please include the following information:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if available)
- Your contact information

### Response Timeline

- **Initial Response**: Within 24 hours
- **Status Update**: Within 72 hours
- **Fix Timeline**: Depends on severity
  - Critical: 1-7 days
  - High: 7-14 days
  - Medium: 14-30 days
  - Low: 30-90 days

### Bug Bounty Rewards

We offer rewards for qualifying security vulnerabilities:

| Severity | Reward Range |
|----------|--------------|
| Critical | $500 - $2000 |
| High     | $200 - $500  |
| Medium   | $50 - $200   |
| Low      | Recognition  |

## Security Best Practices

When using the CyberEx mobile app:

1. ✅ Only download APK from official sources
2. ✅ Enable 2FA authentication
3. ✅ Use strong, unique passwords
4. ✅ Verify APK checksum before installation
5. ✅ Keep your app updated
6. ❌ Don't share your private keys
7. ❌ Don't install from third-party stores
8. ❌ Don't disable security features
